# জনতা মার্ট (Janata Mart) - সম্পূর্ণ ই-কমার্স প্ল্যাটফর্ম

বাংলাদেশের বিশ্বস্ত আধুনিক অনলাইন শপিং প্ল্যাটফর্ম - যা তৈরি করা হয়েছে **React 19, TypeScript এবং Tailwind CSS** দিয়ে। এতে অন্তর্ভুক্ত রয়েছে বাংলাদেশি মোবাইল ব্যাংকিং ও কার্ড পেমেন্ট গেটওয়ে, এসইও (SEO) ফ্রেন্ডলি মেটাডাটা, ডাইনামিক ডেলিভারি চার্জ হিসাব এবং অ্যাডমিন কন্ট্রোল প্যানেল।

---

## 🌟 প্রধান প্রধান ফিচারসমূহ

1. **পেমেন্ট গেটওয়ে সিমুলেশন (Payment Gateways):**
   - **বিকাশ (bKash):** সিমলেস পপআপ, ১১ ডিজিট মোবাইল নম্বর, ৬ ডিজিট ওটিপি (OTP), ৫ ডিজিট পিন ও ভেরিফাইড ট্রানজেকশন আইডি (TrxID)।
   - **নগদ (Nagad):** অ্যাকাউন্ট নম্বর, ওটিপি ও পিন ভেরিফিকেশন।
   - **রকেট (Rocket):** ১২ ডিজিট অ্যাকাউন্ট ও সিকিউর পিন।
   - **কার্ড পেমেন্ট:** Visa, Mastercard, AMEX কার্ড দিয়ে ৩ডি সিকিউর পেমেন্ট।
   - **সরাসরি QR কোড পেমেন্ট:** অ্যাপ দিয়ে সরাসরি স্ক্যান করে পেমেন্টের অপশন।
   - **ক্যাশ অন ডেলিভারি (COD):** পণ্য হাতে পেয়ে নগদ মূল্যে পরিশোধ।

2. **বাংলাদেশি লোকেশন ও ডেলিভারি চার্জ:**
   - বাংলাদেশের ৮টি বিভাগ ও ৬৪+ জেলার সম্পূর্ণ তালিকা।
   - ঢাকা সিটিতে ডেলিভারি চার্জ মাত্র ৳৭০, ঢাকা উপশহরে ৳১০০ এবং ঢাকার বাইরে ৳১৩০।
   - কুপন বা ২০০০ টাকার কেনাকাটায় ফ্রি হোম ডেলিভারি!

3. **এসইও ফ্রেন্ডলি (SEO & Schema.org Structured Data):**
   - ডাইনামিক পেজ টাইটেল ও মেটা ডেসক্রিপশন।
   - সোশ্যাল মিডিয়া শেয়ারিং প্রিভিউ (OpenGraph ও Twitter Card)।
   - Schema.org `OnlineStore`, `WebSite`, এবং প্রতিটি পণ্যের জন্য ডাইনামিক `Product` JSON-LD।

4. **অ্যাডমিন কন্ট্রোল প্যানেল (Admin Panel):**
   - পণ্য তালিকা ও লাইভ স্টক সংখ্যা পরিবর্তন।
   - নতুন পণ্য যুক্ত করা (নাম, ক্যাটাগরি, মূল্য, ছবি ও বিবরণ)।
   - সব অর্ডারের স্ট্যাটাস নিয়ন্ত্রণ (পেন্ডিং, প্রসেসিং, শিপড, ডেলিভার্ড, বাতিল)।
   - মোট বিক্রয় ও অর্ডার পরিসংখ্যান।

5. **অন্যান্য সুবিধাসমূহ:**
   - কুপন কোড সিস্টেম (`JANATA10`, `NEW50`, `FREESHIP`)।
   - লাইভ ৪-ধাপের অর্ডার ট্র্যাকিং।
   - ক্যাশ মেমো / রশিদ প্রিন্ট সুবিধা।
   - গ্রাহকের রিভিউ ও স্টার রেটিং।
   - মোবাইল-ফার্স্ট অ্যাপের মতো বটম নেভিগেশন ও চমৎকার সাউন্ড ইফেক্টস।

## 💻 আপনার কম্পিউটারে যেভাবে চালাবেন (How to Run Locally)

### ১. প্রয়োজনীয় সফটওয়্যার:
- [Node.js](https://nodejs.org/) (ভার্সন 18 বা তার পরবর্তী)

### ২. প্যাকেজ ইন্সটল করুন:
প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে কমান্ড দিন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
কমান্ড দেওয়ার পর আপনার ব্রাউজারে `http://localhost:3000` বা টার্মিনালে দেখানো লিংকে প্রবেশ করুন।

### ৪. প্রডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```
বিল্ড ফাইলগুলো `dist/` ফোল্ডারে জমা হবে, যা যেকোনো হোস্টিংয়ে (Vercel, Netlify, Cloudflare Pages, Firebase Hosting) এক ক্লিকে হোস্ট করা যাবে।
